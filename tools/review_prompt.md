- 주인공: 한국의 공공 AI 교육 회사에서 기획·운영을 하면서 사내 프로덕션 시스템 4개를 직접 만든 사람. 직급 주임.

- README는 GitHub 마크다운 제약(CSS·JS 불가)이라 섹션과 카드를 SVG 이미지로 만들었다.

읽을 파일:

- tools/build_sections.py (배너 아래 패널 5개의 문구·레이아웃 소스)
